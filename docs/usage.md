# QQListener

ClassIsland 的 QQ 消息提醒插件。通过 SnowLuma 内核接收 NT QQ 消息，按规则显示普通、重要或呼叫提醒。

[下载](https://github.com/Sylphy-0xd3ac/QQListener/releases) · [更新日志](https://github.com/Sylphy-0xd3ac/QQListener/blob/main/CHANGELOG.md) · [问题反馈](https://github.com/Sylphy-0xd3ac/QQListener/issues)

## 安装

原生消息捕获仅支持 **Windows x64 + NT QQ**，不支持 TIM。macOS、Linux 可以运行部分开发验证，但不能用于监听 QQ。

1. 安装并登录 NT QQ。
2. 在 ClassIsland 的插件管理中从本地安装 `.cipx`，重启 ClassIsland。
3. 打开插件设置，在「高级设置 → 重新触发安装向导」中安装 SnowLuma 内核。安装前需阅读并接受其许可。
4. 开启监听并设置消息规则，确认接收管道已连接，再发送测试消息。

内核安装后会自动装载，无需每次手动操作。“核心映像已映射”只表示装载阶段完成，不代表消息接收已经连通。

## 配置

规则支持群聊、联系人、关键词和提醒时间段。黑名单优先于白名单；会话白名单留空时不限制来源，填入内容后只提醒匹配的会话。

部分选项的初始值如下，均可在插件设置中调整：

| 选项 | 默认值 |
| --- | --- |
| 排除自己发送的消息 | 开启 |
| 上课时暂停提醒 | 开启 |
| 确定时回复消息 | 关闭 |
| 自动下载文件 | 关闭 |
| 附件下载目录 | 系统桌面 |
| 语音 / 提示音 | 开启 / 关闭 |

只处理聊天消息，撤回、群成员变化、请求与回执等事件不会生成提醒。规则预览可用于检查一条消息为什么被接受、忽略或升级为重要消息。

## 消息与附件

提醒保留正文、图片、文件和引用内容。正文窗口置顶显示，随宿主提醒结束或取消而收起；性能模式关闭模糊与过渡动画。

图片会自动加载。文件默认手动下载，也可开启「自动下载文件」；下载目录可通过输入路径或选择目录修改。已开始的文件下载不因提醒关闭而中断，不会自动打开或执行文件。

### 确定与取消

- 默认情况下，「确定」只收起提醒，不发送消息。
- 开启「确定时回复消息」后，发送预设文本，默认为“收到”。群聊引用原消息，私聊发送普通文本。
- 勾选「使用 OK 表情回应」后，仅为群消息添加 QQ 的 OK 回应，不另发文本。私聊不支持此模式，点击确定只收起提醒。
- 「取消」不回复，并同时结束当前正文窗口和对应的 ClassIsland 提醒，不影响后续消息。

发送失败时保留重试入口。合并摘要中的回复或表情回应针对最后一条消息。

## 暂停与消息队列

需要暂存消息时，请使用「暂停监听」；关闭「启用监听」不等同于暂停积压。暂停期间的消息保存在内存中，默认最多 50 条，超限后丢弃最早的消息，并在恢复提醒时显示丢弃数量。退出 ClassIsland 或卸载内核会清空积压。

开启「上课时暂停提醒」后，上课期间暂存消息，下课后合并展示；可设置课后延迟。手动暂停不会因下课而自动恢复。

同时只播放一条 QQ 提醒，后续消息排队。呼叫优先于重要消息，重要消息优先于普通消息；同一会话的短时连续消息可合并显示。展示队列最多保留 100 项，超限后优先丢弃低等级的最早消息。

正文窗口跟随 ClassIsland 的实际播放、抢占和恢复状态，不独立倒计时。普通消息与合并摘要使用同一套时长设置，摘要按所含消息的最高等级选取时长。

## 自动化与组件

在 ClassIsland 工作流中添加下列触发器或动作。插件不会自动创建工作流。

| 类型 | 标识 | 用途 |
| --- | --- | --- |
| 触发器 | `QQListener.NormalMessageReceived` | 收到普通消息 |
| 触发器 | `QQListener.ImportantMessageReceived` | 收到重要消息 |
| 触发器 | `QQListener.CallingMessageReceived` | 收到呼叫消息 |
| 动作 | `QQListener.SetListenerEnabled` | 设置监听开关 |
| 动作 | `QQListener.ShowLatestMessage` | 重新显示最近一条消息 |
| 动作 | `QQListener.ClearLatestMessage` | 清空最近一条消息 |

“最后 QQ 消息”组件支持最低消息等级、正文显示和隐私模式。隐私模式只显示来源与等级，不显示发送人、会话名或正文。

## 故障排查

### 已装载内核，但收不到消息

确认 QQ 已登录、监听已开启，并查看接收管道状态。若一直等待管道，在高级设置中重新触发安装向导；同时检查最近的忽略原因，排除消息规则或“排除自己发送的消息”的影响。

### 上课或暂停后没有提醒

检查手动暂停状态、课后延迟和消息规则。只有恢复监听且满足课后条件，积压消息才会展示；积压不会在重启后保留。

### 图片无法显示

确认来源 QQ 仍在线。图片下载凭证有有效期，插件在下载凭证失败时会刷新并重试一次。若仍失败，请在反馈中附上图片占位处的错误文字或错误码，不要公开完整下载链接或 `rkey`。

### 确认后没有回复

确认「确定时回复消息」已开启。表情回应仅支持群消息；私聊选择该模式时不会发送回应，也不会自动改发文本。若显示发送失败，请检查对应 QQ 的登录状态后重试。

## 数据与许可

消息筛选与暂停队列在本机处理。下载内核和附件需要网络；语音是否联网取决于 ClassIsland 使用的语音引擎。
